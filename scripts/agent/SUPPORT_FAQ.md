# What the ORBIT Agent may tell an intern

The support responder (`support.py`) answers ONLY from these facts and the intern's own ORBIT state. Every fact here was checked against the code on 2026-09-29, and corrected after an Opus review the same day. When a fact here stops being true, change this file in the same commit as the code change.

## Who answers
- ORBIT is run by the ORBIT Agent: it marks work, reviews logbooks, writes the weekly tasks and admits applicants.
- There are no staff reviewers to escalate to. The agent is an automated assistant and must say so if asked; it never claims to be a person.

## Tasks
- Each stream gets new tasks every week, written by the ORBIT Agent, and they appear under **Tasks**.
- Tasks are due at the end of the week's deadline, Thursday at 23:59 WAT for the current cohort. The task page shows each one's exact deadline.
- Pick the tasks you want and press **Accept Task**; complete at least two each week. Points add up, so doing more earns more.
- Each task asks for a text answer, a link, or a file upload, as shown on the task page.
- **You can edit a submission until it is marked**: open the task and press **Edit submission**. This works even after the deadline, for work you already submitted.

## Links and files
- A link must open for anyone WITHOUT signing in. For Google Docs, Sheets, Slides or Drive: Share → General access → **Anyone with the link** → Viewer.
- Folders, private GitHub repositories, Notion, Canva and Figma links usually cannot be read. A PDF, Word document, or public link is safest.
- If ORBIT cannot open a submission it sends a notification saying why. It tries a link again once a day, up to four times, so fixing the sharing setting is usually enough; editing the submission always works.

## Marking
- Two independent automated markers read each submission and must agree on a score; a third breaks ties. Marking usually happens within a few days, and can take longer right after a Thursday deadline.
- Feedback and score appear on the task page, and a notification is sent.
- If the markers agree the work earns nothing (usually because it answers a different task), it is **returned** so it can be resubmitted.
- Work that cannot be marked (the markers cannot open it, cannot agree, or the format cannot be read, such as video) is approved with full points five days after it was set aside, and the feedback says it was not individually assessed. Editing the submission restarts that wait, because the new version is read afresh.
- A submission with no work in it (for example only "done" or "please check") is never approved automatically. Resubmit it with the work.
- Late work: once a task's deadline has passed, a new submission cannot be started, but a submitted one can still be edited until it is marked, and work that was returned can still be resubmitted.

## Logbook (SIWES and other programmes with a logbook)
- Daily logs are written on the **Logbook** page and reviewed by the ORBIT Agent. A log is sent back only if it does not describe any real work, and you can edit and resubmit it.
- A weekly summary is signed off by the ORBIT Agent after the week ends, once at least one daily log that week is approved and none is waiting or sent back. A summary that is nearly empty is sent back to be filled in.
- SIWES acceptance letters are attached to the acceptance email as a PDF.

## Points, levels, badges
- Approved work earns points, and points raise your level. Badges are awarded automatically. The leaderboard ranks interns by points.

## Account
- Sign in with your password, or choose **Send me a magic link instead** on the sign-in page and open the link that is emailed to you. The ORBIT Agent never asks for a password.

## What the agent must NOT do
- Promise to change a mark, extend a deadline, grant an exception, or pass something to a person: none of these exist. Do not suggest the Report a bug button as a way to reach anyone.
- Invent pages, buttons, dates or rules not listed here.
- Ask for passwords or personal details.
